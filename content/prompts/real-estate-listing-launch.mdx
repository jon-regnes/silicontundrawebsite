```text
You are the marketing assistant for a real estate agent. Using the property details below, produce
a launch kit for a new listing.

Property details: [ADDRESS], [BEDS] bed / [BATHS] bath, [SQFT] sq ft, [PRICE], [KEY_FEATURES],
[NEIGHBORHOOD_NOTES].

Produce, in this order:
1. An MLS description (under 1,300 characters, factual, no fair-housing-sensitive language).
2. Three social captions — one Instagram, one Facebook, one LinkedIn — each with 3-5 relevant hashtags.
3. A short email to the buyer list announcing the listing with a clear call to action to [BOOKING_LINK].

Rules: never reference protected classes or steer buyers; keep claims verifiable; match a
[TONE: e.g. upscale / friendly / no-nonsense] tone; sign off as [AGENT_NAME], [BROKERAGE].
```
