# SMB Pivot & Prompt Library Restructure — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Repivot the site from lifestyle-medicine-only to all SMBs across eight industries, and restructure the prompt library into a function × industry matrix (Approach A).

**Architecture:** Two taxonomy dimensions — `function` (operations/marketing/sales, single-valued per prompt) and `industries` (eight sectors, array). Flat landing pages for each dimension, cross-linked and cross-filtered. The swap is done additive-then-remove so `npm run build` stays green at every task boundary.

**Tech Stack:** Next.js 15 (App Router), TypeScript, Tailwind, MDX via gray-matter + next-mdx-remote.

**Spec:** `docs/superpowers/specs/2026-07-20-smb-pivot-design.md`

## Global Constraints

- **No unit-test framework in this repo.** Each task is verified by: `npm run lint` (clean) + `npm run build` (passes) + the browser/DOM checks named in the task. Do not add a test framework.
- **Stop the dev server before running `npm run build`.** Running a build while `next dev` is live corrupts `.next` (see project memory). Use the Browser-pane preview tools; `preview_stop` before build, `preview_start` after.
- **Design system:** dark theme, `bg-background`/`text-foreground`/`text-muted`/`border-border`/`bg-surface`, accent `text-accent`, `font-heading`/`font-body`, sharp `rounded-sm`. Reuse `components/ui/` primitives — never hand-roll one-off styles.
- **SEO/AEO:** every route needs unique `title` + `description` (or `generateMetadata` for dynamic), an `openGraph.images: [OG_IMAGE]`, single `<h1>`, and inclusion in `sitemap.ts`.
- **Tagline (exact):** "Automated workflows + smarter tools = more time to focus on what your business does best."
- **Type naming:** the function-dimension TS type is `PromptFunction` (never `Function` — it shadows the global).
- **Commit after each task** with a clear message. Do not push (deployment is a separate, later step).

## Task 1: Taxonomy module

**Files:**
- Create: `lib/taxonomy.ts`

**Interfaces:**
- Produces: `INDUSTRIES: Record<Industry,string>`, `FUNCTIONS: Record<PromptFunction,string>`, types `Industry` and `PromptFunction`, guards `isIndustry(v:string): v is Industry`, `isFunction(v:string): v is PromptFunction`.

- [ ] **Step 1: Create the module**

```ts
// lib/taxonomy.ts
// Two prompt-library dimensions. See docs/superpowers/specs/2026-07-20-smb-pivot-design.md.
// Do not rename slugs casually — each is a public URL.

export const FUNCTIONS = {
  operations: "Operations",
  marketing: "Marketing",
  sales: "Sales",
} as const;

export type PromptFunction = keyof typeof FUNCTIONS;

export function isFunction(value: string): value is PromptFunction {
  return value in FUNCTIONS;
}

export const INDUSTRIES = {
  "field-services": "Home, Commercial & Field Services",
  "real-estate": "Real Estate",
  manufacturing: "Specialty Manufacturing & Industrial",
  "lifestyle-medicine": "Lifestyle Medicine",
  logistics: "Logistics",
  "rentals-b2b": "Rentals & B2B Operations",
  "pet-care": "Animal & Pet Care",
  agriculture: "Agriculture & Extraction",
} as const;

export type Industry = keyof typeof INDUSTRIES;

export function isIndustry(value: string): value is Industry {
  return value in INDUSTRIES;
}
```
